# LiveKeeping Tally Sync (Standalone)

This folder contains the executable Tally Sync Client.

## 🚀 How to Run
1. Make sure Tally ERP 9 / Prime is running by opening it.
2. Double-click **StartSync.bat** (Recommended) or **TallySync.exe**.
3. A black window will open showing the sync progress.

## ⚙️ Configuration
The settings are loaded from `index.js` internally, but for this portable version, 
ensure your **Tally ODBC Server** is running on Port **9000**.

## 📁 Logs
Check `sync.log` in this folder for detailed success/error reports.
